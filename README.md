# 廟會遶境路線（pg-pilgrim）

十八刻內規劃一趟抽象廟會遶境：從主壇出發，走訪三座指定小壇，應變車潮、陣頭交會與午後驟雨，再平安回壇。

## 執行

本遊戲是無 build、無套件依賴的純 HTML／CSS／JavaScript SAM。

```sh
python3 -m http.server 4173
```

開啟 <http://localhost:4173>。

## 測試

```sh
npx vitest run
```

不安裝或提交 `node_modules`。

## 規則摘要

- 地圖共有 12 個街口；只能沿相鄰街路移動。
- 北境、東境、水岸三座小壇都要走訪，並在第 18 刻內回到主壇才具計分資格。
- 街路消耗時辰與體力；歇腳恢復體力，協調隊可一次通過活動封路。
- 香市、小壇、補給站提供香火、體力或捷徑。
- 車潮與陣頭交會會封路，午後驟雨會拖慢河岸路段。
- 重複繞入住宅與入夜鼓聲增加擾動；擾動達 6 時，香火只計一半。
- 得分＝計入香火＋剩餘體力−擾動；不合格返程得 0 分。
- 最佳分數與近期成功路線透過 `/api/kv/pilgrim:best`、`/api/kv/pilgrim:routes` 保存；靜態預覽無 API 時仍可玩。

## 文化呈現

遊戲只使用自創名稱與抽象的燈、鼓、壇、街區符號，不包含真實宮廟、神像、商標或團體識別。
